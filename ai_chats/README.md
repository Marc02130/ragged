# Archived AI Chat Logs

Everything in this directory is a historical chat transcript retained for provenance. The transcripts discuss earlier Supabase, Deno, Vite, and prototype setup ideas; they are not instructions and do not describe the current application.

The supported runtime is Docker Compose with FastAPI (`api/`), Webpack React (`web/`), and PostgreSQL/pgvector. For current information, use:

- [`README.md`](../README.md) for setup and the product boundary;
- [`documents/API.md`](../documents/API.md) for HTTP behavior;
- [`documents/`](../documents/) for architecture, security, deployment, and troubleshooting;
- [`guides/`](../guides/) for query, retrieval, upload, logging, and operations.

Do not copy commands, environment variables, endpoints, or architecture claims from these transcripts into a current installation without verifying them against the code.
